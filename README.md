# 🌟 Project Overview

**E-Commerce Testing Suite** is a modern full-stack shopping application designed specifically for **Software Quality Assurance (QA)** and **Automation Testing**.

The project simulates a real online shopping platform while showcasing industry-standard testing methodologies used by QA engineers.

It covers:

* ✅ Manual Testing
* ✅ API Testing
* ✅ End-to-End Automation
* ✅ Unit Testing
* ✅ Integration Testing
* ✅ Regression Testing
* ✅ Bug Reporting
* ✅ Test Documentation

This project demonstrates the complete software testing lifecycle from feature validation to defect reporting.

# ⚙️ Installation

## Clone Repository

```bash
git clone https://github.com/yourusername/ecommerce-testing-suite.git

cd ecommerce-testing-suite
```

---

## Backend Setup

```bash
cd server

npm install

npm run dev
```

---

## Frontend Setup

```bash
cd client

npm install

npm run dev
```

---

# ▶️ Running Tests

## Cypress

```bash
npx cypress open
```

---

## Jest

```bash
npm test
```

---

## Postman

Import the provided Postman Collection and Environment files to execute API tests.
